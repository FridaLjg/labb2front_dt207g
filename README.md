# Laboration 2 - DT207G

## Av: Frida Ljungberg, 2026.

### Om
Syftet med denna webbplats är att presentera och hantera arbetserfarenheter via en egenutvecklad webbtjänst.
Kommunikation mellan webbplatsen och webbtjänsten sker med hjälp av Fetch API och data skickas och hämtas i JSON-format.

Webbplatsen har tre sidor: 
* Startsida - Visar alla registrerade arbetserfarenheter som hämtas från webbtjänsten med ett GET-anrop. 
* Lägg till arbetserfarenhet - Innehåller ett formulär där användaren kan registrera en ny arbetserfarenhet.
* Om - Innehåller information om webbplatsen, databasservern som används samt slutsatser från arbetet med uppgiften.
